# Chiikawa artwork and logo

Generated with the built-in image generation tool, with actual alpha transparency. These are generated fan illustrations, not official artwork. The originals are preserved; the extension uses smaller local derivatives.

- Header illustration: `assets/chiikawa-friends.webp` (900px wide); original: `assets/chiikawa-friends-source.png`.
- Animated library logo: `assets/logo.png` (256px), animated through transform/opacity keyframes in `library.css`; original: `assets/logo-source.png`.
- Matching Chrome toolbar and extension icons: `assets/icon-16.png`, `assets/icon-32.png`, `assets/icon-48.png`, and `assets/icon-128.png`.
- No online image service or third-party font request is needed at runtime.
